在 Windows 上搭 Flutter 环境，踩坑多半集中在 **国内网络、JDK 版本、Android SDK 路径、模拟器显卡加速**。本文按「能跑起来 `flutter doctor` 全绿」为目标，整理一套可复用的配置步骤。

### 一、国内镜像（建议先配）

在系统或用户环境变量中增加：

```bash
PUB_HOSTED_URL=https://pub.flutter-io.cn
FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
```

配置后重新打开终端，可显著加速 SDK 与依赖下载。若镜像不可用，可改用社区维护的备用源并查阅 [Flutter 中文网](https://flutter.cn/) 最新说明。

### 二、JDK

Flutter Android 构建依赖 JDK，推荐 **JDK 8 或 JDK 11**（与 Android Gradle Plugin 版本对齐）。安装后确认：

```bash
java -version
```

### 三、安装 Flutter SDK

**方式 A：Git 克隆（便于升级）**

```bash
git clone -b stable https://github.com/flutter/flutter.git
# 解压或 clone 到例如 D:\dev\flutter_sdk\flutter
```

**方式 B：官网下载 stable 压缩包解压到指定目录。**

将 `flutter\bin` 加入 `PATH`：

```bash
# PowerShell 临时生效示例
$env:PATH = "D:\dev\flutter_sdk\flutter\bin;$env:PATH"
```

永久生效：系统环境变量 `Path` 中追加 `...\flutter\bin`。

验证：

```bash
flutter --version
```

### 四、Android Studio

1. 安装 [Android Studio](https://developer.android.com/studio)。
2. **Settings → Languages & Frameworks → Flutter**：指向 Flutter SDK 根目录（例如 `D:\dev\flutter_sdk\flutter`）。
3. 安装 Android SDK、SDK Platform-Tools、Build-Tools（按 Android Studio 向导即可）。

**创建模拟器（AVD）**

- 打开 **Tools → Device Manager → Create Virtual Device**
- 系统镜像建议 **x86 / x86_64**
- **Emulated Performance** 选择 **Hardware - GLES 2.0**，启用硬件加速
- Finish 后启动 AVD 验证能否正常开机

### 五、环境检测

```bash
flutter doctor --android-licenses   # 一路 y 接受协议
flutter doctor
```

逐项解决 `doctor` 标红项：常见是 Android licenses 未接受、`ANDROID_HOME` 未配置、或 cmdline-tools 缺失。

### 六、Android SDK 环境变量

| 变量 | 示例值 |
|------|--------|
| `ANDROID_HOME` | `C:\Users\<你的用户名>\AppData\Local\Android\Sdk` |
| `Path` 追加 | `%ANDROID_HOME%\platform-tools` |

修改后**重启终端**（必要时重启 IDE），执行 `adb devices` 应能看到模拟器或真机。

### 七、项目启动

```bash
cd your_flutter_project
flutter pub get          # 拉取依赖
flutter packages upgrade # 可选：升级依赖锁
flutter run              # 连接设备或模拟器运行
```

若项目使用空安全或额外编译参数，按仓库 README 追加，例如：

```bash
flutter run --dart-define=APP_ENV=dev
```

Legacy 项目若仍依赖旧 SDK，可能需 `--no-sound-null-safety`，**以项目文档为准**，新项目默认应开启 null safety。

### 八、常见问题

| 现象 | 处理 |
|------|------|
| `Gradle` 下载慢 | 配置国内 Maven 镜像或使用 Android Studio 自带代理 |
| 模拟器黑屏 | 检查 HAXM / Hyper-V 冲突，换 x86_64 镜像 |
| `flutter doctor` Android 项叉 | 确认 SDK 路径与 licenses |
| 真机调试 | 开启 USB 调试，安装对应 OEM 驱动 |
